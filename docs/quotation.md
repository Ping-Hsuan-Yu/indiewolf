# 報價單 — IndieWolf 插畫家個人作品集網站

> **專案名稱**：IndieWolf — 插畫家個人品牌官網  
> **報價日期**：2026/02/22  
> **報價有效期**：30 天  
> **幣別**：新台幣（NTD）

---

## 一、專案概述

為插畫家/漫畫家客戶建立個人品牌官方網站，包含**前台作品展示**與**後台內容管理系統 (CMS)**，支援**中英雙語**切換，整合**雲端圖片管理**與**資料庫**，部署於 Vercel。

---

## 二、技術規格

| 項目      | 技術選型                          |
| --------- | --------------------------------- |
| 前端框架  | Next.js 16 (App Router, React 19) |
| 樣式系統  | Tailwind CSS 4                    |
| UI 元件庫 | shadcn/ui (Radix UI)              |
| 語言      | TypeScript                        |
| 多語系    | next-intl (中文 / 英文)           |
| 資料庫    | Supabase (PostgreSQL)             |
| 圖片管理  | Cloudinary + next-cloudinary      |
| 認證系統  | Supabase Auth                     |
| 部署平台  | Vercel                            |
| 拖曳排序  | dnd-kit                           |
| 圖片瀏覽  | yet-another-react-lightbox        |
